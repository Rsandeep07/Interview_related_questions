# Interview Preparation – Python, NumPy & Power BI

This repository contains a structured and curated collection of **interview questions,
clear explanations, and hands-on practice materials**
focused on **Python, NumPy, and Power BI**.

The content is prepared as part of my **daily interview preparation**
and is intended for **Data Analyst, Business Intelligence, and AI/ML-related roles**.

---

## Contents

### Python
<!-- Core Python interview coverage -->
- Core Python concepts
- Data types and data structures
- Functions, OOP, and exception handling
- Coding and logic-based interview questions
- Real-world problem-solving scenarios
- Python usage in data analysis and ML workflows

### NumPy
<!-- Practical + conceptual NumPy interview preparation -->
- NumPy array creation and manipulation
- Differences between Python lists and NumPy arrays
- Array indexing, slicing, and reshaping
- Vectorized operations and broadcasting
- Mathematical and statistical functions
- Interview-oriented conceptual questions
- Practical examples using NumPy for data processing

### Power BI
<!-- End-to-end Power BI interview topics -->
- Power BI fundamentals
- Power BI Desktop vs Service
- Data modeling and relationships
- Power Query and M basics
- DAX (measures, calculated columns, time intelligence)
- Import vs DirectQuery
- Performance optimization techniques
- Row-Level Security (RLS)
- Power BI Service, Gateway, and administration
